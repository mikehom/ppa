## Technical Analysis / Mechanism

Lemma 6.4 Part (ii) [PPA Lemma 6.4, p. 370] (book p. 370; PDF p. 386) [PPA §6.1.1, p. 371] (book p. 371; PDF p. 387) proves F_S(Analysis) <= Analysis by tracking the last update to some y in FV(t), which is vacuous on constant constraints with FV(t) = empty unless Step 1 seeding in Table 6.1 [PPA Table 6.1, p. 369] (book p. 369; PDF p. 385) is invoked as the base witness. Crucially, Part (i) holds Analysis_i <= mu_S throughout Step 2 while reductiveness (Analysis in Red(F_S)) holds ONLY when W = empty; aborting on a step cap with W != empty silently returns an under-approximation missing reachable flows. Finally, the O(h * M^2 * N) bound [PPA §6.1.1, p. 372] (book p. 372; PDF p. 388) hides O(|D|/w) set-union and O(log N) priority-queue costs when O(1) ADT operations do not hold.

Guardrail: Handle FV(t) = empty via Step 1 seeding, document exact bitset/heap factors, and forbid silent early returns when W != empty. (Refs: F-U6-03, G-U6-06, G-U6-07, G-U6-08).
