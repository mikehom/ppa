## Summary

Section 5.3.4 defines dom(theta_A) = AV(C) (undefined otherwise), which fails to cover unconstrained annotation variables in (AV(theta Gamma_hat) union AV(tau_hat)) \ AV(C) such as '1 in fn_X x => x 1.

## Technical Analysis / Mechanism

Section 5.3.4 [PPA §5.3.4, p. 319] (book p. 319; PDF p. 336) defines the minimal annotation substitution theta_A(beta) = {pi | (beta >= {pi}) in C} on dom(theta_A) = AV(C) and 'undefined otherwise'. However, Corollary 5.23 [PPA Corollary 5.23, p. 318] (book p. 318; PDF p. 335) requires theta_G = theta_A o theta_T to be a ground substitution covering every annotation variable in AV(theta Gamma_hat) union AV(tau_hat). On fn_X x => x 1 (or Mini Project 5.3 [PPA Mini Project 5.3, p. 355] (book p. 355; PDF p. 372)), the parameter arrow carries a fresh annotation variable '1 appearing in tau_hat but absent from C, so applying theta_A leaves '1 ungrounded unless unconstrained variables default to empty.

Guardrail: Default theta_A(beta) = empty for all beta in (AV(theta Gamma_hat) union AV(tau_hat)) \ AV(C) when constructing covering ground validations. (Refs: F-U5a-08, F-U5b-01, G-U5a-19, G-U5a-21, G-U5b-01).
