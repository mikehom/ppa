Figure 2.9 labels call edge f̂¹_{ℓ₁} instead of f̂¹_{ℓ_c}; Example 2.40 writes Δ = Lab ∪ {Λ} instead of length-<=1 sequences Lab⋆^{<=1} and 'does not harm'.

## Technical Analysis / Mechanism

Two local notation discrepancies appear in `§2.5.3–§2.5.4`: (1) `Figure 2.9` (illustration of faulty unary return transfer) prints `f̂¹_{ℓ₁}` on the call arrow where surrounding call/return schemas (`Figure 2.8`, `Figure 2.10`) index by call label `ℓ_c`; (2) `Example 2.40` informally writes `Δ = Lab ∪ {Λ}` for `k = 1` call strings, conflating element labels `ℓ ∈ Lab` with length-1 singleton sequences `[ℓ] ∈ Lab⋆^{≤1}` (whereas `[δ, ℓ_c]` concatenation operates on sequences, matching `Δ = {Λ, [9], [4], [6]}` in `Example 2.39`).

Guardrail: Index call transfer consistently by ℓ_c and distinguish length-1 call strings [ℓ_c] from bare labels. (Refs: F-U2b-04, F-U2b-05, G-U2b-09, G-U2b-10).
