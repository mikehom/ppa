## Summary

G = (N, A) has a finite node set and A ⊆ N × N, so at most one directed edge `(n₁, n₂)` per ordered node pair (opposite-direction edges `(n₁, n₂)` and `(n₂, n₁)` are permitted, as in Figure C.3, whereas parallel same-direction multi-edges are excluded; G-U0-26).

## Technical Analysis / Mechanism

Real control-flow graphs can have several edges between the same nodes (switch cases, exceptional edges); collapsing them changes edge counts used in bounds and in Example C.8.
