## Summary

One-armed 'if c <= t_1 then t_2' terms omit an explicit false branch and require registering both guard and payload variables in infl; lazy online simplification also adds edges that can merge SCCs.

## Technical Analysis / Mechanism

Example 6.2 [PPA Example 6.2, p. 367] (book p. 367; PDF p. 383) and Example 6.6 [PPA Example 6.6, p. 373] (book p. 373; PDF p. 389) encode Chapter 3 conditional implications as one-armed 'if c <= t_1 then t_2' terms without an explicit else-clause. If an evaluator leaves the false branch undefined or omits payload variables FV(t_2) from infl, updates to t_2 after the guard becomes true never re-trigger the constraint, silently freezing downstream flow variables below mu_S. Conversely, lazy online simplification in Mini Project 6.2 [PPA Mini Project 6.2, p. 388] (book p. 388; PDF p. 404) dynamically inserts new graph edges x_2 -> x upon guard activation, which can merge previously acyclic nodes into an SCC and invalidate static srPostorder priorities.

Guardrail: Evaluate false guards to bot_L (empty set) and register full FV(t_1) U FV(t_2) in infl (or re-enqueue and register payload on lazy activation). (Refs: F-U6-02, G-U6-05, G-U6-20).
