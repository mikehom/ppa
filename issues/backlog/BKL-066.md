## Summary

For eta : V -> D, Exercise 4.14 asks to verify varsigma_eta(V') = V' cap eta[V], using concrete-subset metavariable V' instead of D' subseteq D as printed on p. 246.

## Technical Analysis / Mechanism

Given extraction function eta : V -> D, the lifted Galois connection (P(V), alpha_eta, gamma_eta, P(D)) reduces subsets inside the abstract classifier powerset P(D). Writing varsigma_eta(V') = V' cap eta[V] applies the abstract reduction operator to concrete-set metavariable V' subseteq V, ill-typing the intersection whenever V != D.

Guardrail: Type varsigma_eta : P(D) -> P(D) on abstract subsets D' subseteq D via varsigma_eta(D') = D' cap eta[V] matching p. 246 (Refs: F-U4b-12, G-U4b-23).
