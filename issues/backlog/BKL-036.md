## Summary

Printed signatures declare ud, du, UD, DU over Lab⋆ even though ud(z, 3) = {?} returns '?' and du(z, ?) = {3} branches on '?'.

## Technical Analysis / Mechanism

When an execution reads a variable `x` before any intervening assignment reaches that label, `RD_entry(ℓ')` contains `(x, ?)`. Under `Example 2.12` (`[z=x]^3` with uninitialised `z`), `UD(z, 3) = {?}` and `DU(z, ?) = {3}`. Typing these maps strictly as `Var⋆ × Lab⋆ → 𝒫(Lab⋆)` excludes `?` from valid indices, dropping uninitialised-use edges or failing domain assertions (`? ∉ Lab⋆`, `BKL-035`) inside `Mini Project 2.1` constant-folding checks (`? ∈ UD(x, ℓ')` must block rewriting).

Guardrail: Type all ud/du/UD/DU APIs cleanly with Lab⋆^? = Lab⋆ ∪ {?} in domain/codomain. (Refs: F-U2a-05, G-U2a-14, BKL-035).
