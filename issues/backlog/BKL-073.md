## Technical Analysis / Mechanism

In Table 5.5 [PPA Table 5.5, p. 303] (book p. 303; PDF p. 320), step 1 computes (tau_0, theta_0) = W_UL(Gamma, e_0) and threads theta_0 Gamma into e_1, but the final return tuple (theta_4(theta_3 tau_2), theta_4 o theta_3 o theta_2 o theta_1) drops o theta_0. On Gamma = [b |-> 'a] and e = if (b < 5) then 1 else 2, e_0 forces theta_0 = ['a |-> int], while theta_1..theta_4 are all id; returning theta = id leaves 'a unconstrained in theta Gamma, breaking Theorem 5.20 syntactic soundness because ground instantiation ['a |-> bool] produces an ill-typed guard (bool < 5). Table 5.8 [PPA Table 5.8, p. 310] (book p. 310; PDF p. 327) restores o theta_0.

Guardrail: Compose the full chain theta_4 o theta_3 o theta_2 o theta_1 o theta_0 as corrected in Table 5.8. (Refs: F-U5a-04, G-U5a-14).
