## Summary

Example 2.30 states h <= v*b overlooking the v initial pairs (x, ?) (so h <= v*(b+1)), and label consistency gives h <= b+v -> O(b^2) when v = O(b).

## Technical Analysis / Mechanism

Each variable `x ∈ Var⋆` can carry its uninitialised reaching pair `(x, ?)` alongside labelled definitions `(x, ℓ)` (`|Lab⋆^?| = b + 1`), so the full height of `(𝒫(Var⋆ × Lab⋆^?), ⊆)` is `h ≤ v · (b + 1)` rather than `v · b`. Even under label consistency (where each label `ℓ` maps to at most one assigned variable `x`, giving `b` labelled pairs), there remain up to `v` distinct uninitialised pairs `(x, ?)`, yielding `h ≤ b + v` and total worklist complexity `O(e · (b + v)) = O(b · (b + v))`; `O(b²)` holds only under the hidden regularity assumption `v = O(b)`.

Guardrail: Include (x, ?) in lattice height accounting and state v = O(b) side condition when quoting O(b^2). (Refs: F-U2a-14, G-U2a-31).
