## Summary

The total function space S → L preserves finite height, ACC and DCC only when S is finite; the monotone function space does not preserve them in general.

## Source Citations & Grounding

- [PPA §A.3, p. 400] (book p. 400; PDF p. 416)
- [PPA §A.4, p. 403] (book p. 403; PDF p. 419)
- Statements confirmed against rendered page images during Unit 0 extraction.

## Technical Analysis / Mechanism

Analysis states keyed by unbounded sets (heap addresses, strings, call strings) lose ACC even when the value lattice is tiny: in the total function space ℕ → {0 ⊑ 1} over discrete set S = ℕ, the indicator functions of {0,…,n} form a non-stabilising ascending chain, so iteration from ⊥ need not terminate (G-U0-08, G-U0-09).

Guardrail: L2: before claiming termination, confirm that every map-shaped domain has a finite key set or a finite partition (summary keys), or supply a widening.
