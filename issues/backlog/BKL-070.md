## Summary

Mini Project 4.1 defines 'x is a suffix of y' asymmetrically (n + k = m, k >= 0, giving |LR| = 16) and five lines later glosses S as 'one list is a suffix of the other' (symmetric, giving |LR| = 20).

## Source Citations & Grounding

- [PPA Mini Project 4.1, p. 274] (book p. 274; PDF p. 291)
- Statements confirmed against rendered page images during Unit 4 extraction and Gate #6 audit.

## Technical Analysis / Mechanism

When forming LR subseteq P({H, S}) x Range, the formal condition n + k = m (k >= 0) makes S asymmetric (x is a suffix of y, forcing length(x) <= length(y)), which eliminates the four (+1 / >+1) S-combinations to leave |LR| = 16 atoms. Five lines lower, prose summarises S symmetrically ('one list is a suffix of the other'), re-enabling {S} and {H, S} at +1 and >+1 for |LR| = 20 atoms.

Guardrail: Specify explicitly whether S tracks directional suffixes (16 atoms) or symmetric suffixes (20 atoms), keeping ([], []) -> ({S}, 0) in both (Refs: F-U4b-09, G-U4b-22).
