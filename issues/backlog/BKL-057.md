Page 191 defines CEnv = Var -> Delta as total functions whereas Table 3.10 restricts ce_0 = ce | FV(...) and Example 3.34 writes ce_0 = []; Example 3.34 mis-cites "Example 3.33" while analysing Example 3.32's uncloned term and prints "only records".

## Technical Analysis / Mechanism

Total `CEnv = Var -> Delta` makes `Val_hat = P(Term x CEnv)` infinite/unbounded over all `Var` unless restricted to finite partial maps `Var ->_fin Delta` over `ce | FV(e)` (`ce_0 = []` for closed terms as in Example 3.34). Note also that §3.6.1 p. 193 prose matches Table 3.10 `[var]` cleanly (`rho_hat(x, ce(x))`), while Example 3.34 mis-cites Example 3.33 (`C'_id(8, Lambda) = C'_id(9, Lambda) = {(fn y => y^6, ce_0)}`).

Guardrail: Represent CEnv via finite FV-restricted maps (ce | FV(...)), query lexical rho_hat(x, ce(x)), push outer label l only at [app] (unchanged at [let]), and compress stuttering on recursion (Exercise 3.15). (Refs: F-U3b-03, F-U3b-04, G-U3b-11..16, G-U3b-29, BKL-007).
