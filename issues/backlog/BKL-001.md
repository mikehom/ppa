## Summary

The book evaluates arithmetic over unbounded integers and states that no errors can occur (division by 0 must still produce an integer); the Interval lattice ranges over integers extended with infinities. [external] Machine arithmetic wraps modulo 2^w or is undefined on signed overflow; the book does not discuss machine arithmetic.

## Technical Analysis / Mechanism

[external] An Interval transfer function sound over the integers is unsound over 32/64-bit two's-complement values: [0, MAX] + [1, 1] is [1, MAX+1] mathematically but wraps negative at runtime, defeating upper-bound checks; folding that relies on signed-overflow UB can delete overflow guards.

Guardrail: L2 procedures that reuse Interval/Sign analyses on machine integers must state the wrap-around model (wrapped intervals [external]) or add explicit overflow proof obligations; division by zero is a fault sink.
