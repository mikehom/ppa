Sections 5.1-5.3 require |-_UL typability (rejecting fn x => x x), assume base-only Const/Op and monomorphic let, discard internal call arrows from root types, smear monomorphic arguments bidirectionally, and rely on closed big-step evaluation.

## Technical Analysis / Mechanism

Four structural gates constrain §§5.1-5.3: (1) Fact 5.6 [PPA Fact 5.6, p. 291] (book p. 291; PDF p. 308) ties |-_CFA to Table 5.1 |-_UL [PPA Table 5.1, p. 285] (book p. 285; PDF p. 302), so Robinson's occurs check rejects untyped self-application (fn x => x x) before analysis begins; (2) Table 5.2 [app] [PPA Table 5.2, p. 288] (book p. 288; PDF p. 305) drops the operator's arrow annotation from the conclusion, requiring the full derivation tree (Example 5.4 [PPA Example 5.4, p. 289] (book p. 289; PDF p. 306) and Exercise 5.4 display (5.2) [PPA Exercise 5.4, p. 359] (book p. 359; PDF p. 376)) to recover per-label C_hat(l); (3) monomorphic [let] and equality on [app] domain types smear argument annotations across distinct call sites; and (4) big-step Table 5.4 [PPA Table 5.4, p. 292] (book p. 292; PDF p. 309) lacks finite trees for diverging loops, making Theorem 5.9 [PPA Theorem 5.9, p. 295] (book p. 295; PDF p. 312) vacuous on non-terminating servers.

Guardrail: Enforce TYPED_SUBSTRATE_GATE, persist per-node AST type side tables ((5.2)), upgrade to §5.4 subtyping/polymorphism to eliminate smearing, and pair reactive loops with small-step SOS.
