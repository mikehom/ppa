## Technical Analysis / Mechanism

Node-attached Monotone Frameworks apply transfer functions per block before branching along F, forcing f_ell^{SS}([b]^ell) = Sigma = id (Remark p. 266) so false-branch states leak into true-branch targets and SS strictly over-approximates collecting semantics. On p. 267, the Constant Propagation transfer for [x := a]^ell further assumes smash-bottom short-circuiting sigma_hat != bot tacitly before evaluating A_CP[[a]](sigma_hat).

Guardrail: Attach [external] branch-guard filter transfers to flow edges (ell_1, ell_2) (Exercise 2.11) when guard refinement is required, and guard sigma_hat = bot explicitly (Refs: F-U4b-04, G-U4b-14, G-U4b-15).
