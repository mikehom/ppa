## Summary

Adding S → S leaves the inductive reading of Example B.2 unchanged but makes the coinductive reading all of {0,1,2}^∞; lfp and gfp coincide for the contractive functional 𝒬₀ but not for 𝒬₁–𝒬₃. Excluding strings containing 2 from the coinductive reading uses an inductive argument.

## Technical Analysis / Mechanism

Checkers that accept a goal already on the visited stack implement gfp; an unguarded self-reference (A trusts A, type T = T) is then accepted, widening acceptance to everything (G-U0-25). By §B.2 (p. 410), requiring recursive calls to strictly decrease along a well-founded order (such as (ℕ, <) for 𝒬₀) collapses lfp = gfp (G-U0-21) — whereas on non-well-founded infinite strings {0,1,2}^∞ (Example B.2), productive constructor-guarded rules admit {0,1}^ω under gfp without collapsing to lfp. Conversely, assuming gfp-defined sets need only coinductive reasoning misses the inductive step of Example B.2.

Guardrail: L2: state whether a recursive specification uses lfp or gfp; reject unguarded trivial self-rules in coinductive checkers by requiring productive/constructor-guarded recursion `[external]` (whereas strictly decreasing recursion along a well-founded order forces lfp = gfp).
