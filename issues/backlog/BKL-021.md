## Summary

The iteration chain uses fⁿ(⊥) with f⁰(⊥) = ⊥, while the transfinite remark defines f^{↑n} = fⁿ⁺¹(⊥) for natural n.

## Technical Analysis / Mechanism

Quoting an iteration count from one indexing in the other is off by one — a SIGNATURE_DISTORTION in any bound stated in iterations.

Guardrail: Every iteration count above L3 names its indexing (fⁿ(⊥) vs f^{↑n}).
