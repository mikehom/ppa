## Summary

Live Variables analysis may be used as the basis for Dead Code Elimination: an assignment to a variable that is not live at the exit from its label can be eliminated [PPA §2.1, p. 49] (book p. 49; PDF p. 68). The analysis is defined in Table 2.4 with no variables live at the end of the program; the book itself cautions on the same page that "for some applications it might be better to assume that all variables are live at the end of the program". Faint-variable analysis (Chapter 2 Exercises) strengthens the licence.

## Technical Analysis / Mechanism

[external] Zeroing a key buffer before return is exactly such a dead store; an optimiser applying the analysis removes it and leaves secrets in memory.

Guardrail: L2 (transformations, cyber): apply the book's own caveat on p. 49 and treat explicitly-observable stores as live at exit; flag zeroization of dead locals lacking a barrier.
