## Summary

℘, 𝒜, ℬ are defined on infinitely many (σ, ℋ) ∈ State × Heap yet write →_fin ('partial function with finite domain') instead of plain partial arrow ⇀.

## Source Citations & Grounding

- [PPA §2.6.1, p. 107] (book p. 107; PDF p. 126)
- [PPA §2.6.1, p. 108] (book p. 108; PDF p. 127)

## Technical Analysis / Mechanism

Concrete semantic maps `℘ : (PExp × State × Heap) →_fin (Z + Loc + {◇})`, `𝒜`, and `ℬ` range over curried pairs `(σ, ℋ)` from `State × Heap`, which is infinite (`State = Var⋆ → (Z + Loc + {◇})` and unbounded `Loc`). Since the domain of `℘`, `𝒜`, and `ℬ` is infinite (while `ℋ ∈ (Loc × Sel) →_fin ...` genuinely has a finite domain), typing `℘, 𝒜, ℬ` with `→_fin` ("partial function with finite domain", `[PPA Preface, p. VIII]`) is ill-typed and must be read as ordinary partial functions `⇀`.

Guardrail: Interpret ℘, 𝒜, ℬ as ordinary partial functions ⇀ over infinite State × Heap. (Refs: F-U2b-08, G-U2b-16).
