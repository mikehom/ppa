## Summary

Syntactic Ann needs finite Pnt_* or P(Pnt) for completeness, and replacing §5.2.3's covariant domain precision order with §5.4's contravariant subtyping order breaks Proposition 5.12's Moore family on fn_X x => x.

## Technical Analysis / Mechanism

Proposition 5.12 [PPA Proposition 5.12, p. 299] (book p. 299; PDF p. 316) proves JUDG_CFA[Gamma |-_UL e : tau] is a Moore family under the pointwise covariant order <=_cov on Type_hat[tau] [PPA §5.2.3, p. 298] (book p. 298; PDF p. 315) (requiring finite Pnt_* or P(Pnt) so arbitrary meets exist). When a solver instead orders function types by §5.4.1's behavioral subtyping <= [PPA §5.4.1, p. 324] (book p. 324; PDF p. 341) (contravariant in domains, covariant in codomains), Exercise 5.9 [PPA Exercise 5.9, p. 361] (book p. 361; PDF p. 378) shows that two valid typings of fn_X x => x with different domain annotations have greatest lower bound (tau_1 u tau_2) --{X}--> (tau_1 n tau_2), whose codomain no longer accepts its widened argument, violating Moore-family closure and preventing a single unconstrained least typing.

Guardrail: Keep precision order <=_cov and behavioral subtyping <= distinct; use constrained type schemes when combining subtyping with polymorphism. (Refs: G-U5a-12, G-U5a-13, G-U5b-07).
