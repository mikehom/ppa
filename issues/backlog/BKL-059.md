## Technical Analysis / Mechanism

Because `0-CFA` `Env_hat = Var -> Val_hat` keys variables by raw name, two distinct functions or nested `let` blocks declaring `x` merge values unless `alpha`-renamed to unique identifiers. In Set-Constraint Based Analysis (p. 201), union `∪`, intersection `∩`, constructors `C(...)`, and projections `C^{-i}(S)` are monotone on `(P(U), <=)`, whereas explicit complement `¬S` (anti-monotone) and variable-LHS conditional guards `(S1 <= S2) => S3` violate monotonicity so Tarski's Fixed Point Theorem fails and Banach's Contraction Theorem is needed. Separately, `[9]`'s (`[external: Aiken et al.]`) lazy expansion skips unreachable closures eagerly seeded by `Table 3.6`.

Guardrail: Alpha-rename distinct variable bindings before 0-CFA, exclude ¬S / variable-LHS guards from monotone Tarski solvers, and distinguish lazy [9] reachability from whole-AST Table 3.6. (Refs: G-U3a-03, G-U3b-22, G-U3b-23, G-U3b-24).
