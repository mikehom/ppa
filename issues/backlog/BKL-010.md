## Summary

Uniquely labelled WHILE programs yield reducible graphs (Example C.13); Figure C.3 shows an irreducible graph. For instances of a Bit Vector Framework iterated in reverse postorder of a depth-first spanning forest T, the Round Robin bound of Lemma 6.12 (`d(G_S, T) + 3` iterations) is stated in terms of the loop connectedness parameter `d(G_S, T)`.

## Technical Analysis / Mechanism

[external] Binaries, goto-heavy C and obfuscated code produce irreducible graphs in which back edges depend on the spanning forest, natural-loop headers are ill-defined, and `d(G_S, T)` varies with the chosen DFSF `T`; moreover, non-bit-vector frameworks do not inherit Lemma 6.12's `d(G_S, T) + 3` cap.

Guardrail: L2: use strong components (§6.3) rather than structural reduction; quote `d(G_S, T) + 3` only for Bit Vector Framework instances with DFSF `T` and reverse postorder; [external] place widening at DFSF back-edge targets.
