## Summary

IAV(p) = (AV(S) \ {x}) ∪ ... subtracts val formal x but forgets res formal y (leaking callee res writes as global mutations, masked in Example 2.42), and pp. 102-103 write 'context-insensitive' for flow-insensitive.

## Technical Analysis / Mechanism

Under `§2.5.6`, `IAV(p)` should exclude parameters/locals scoped strictly inside `p`'s stack frame so only globally visible modifications propagate across `CP(S)`. Omitting `res y` from `AV(S) \ {x}` causes every write to out-parameter `y` inside `p` to remain in `IAV(p)` and falsely taint callers across the call graph (masked in `Example 2.42` only because `fib` and `add` carry no `res` parameter); meanwhile `pp. 102–103` twice misname flow-insensitive summaries as "context-insensitive". Solving `IAV` for `gfp` degenerates to `Var⋆` on self-recursive cycles (`fib`).

Guardrail: Subtract ALL formals and locals ({x, y}) in IAV(p) and solve for least fixed point. (Refs: F-U2b-07, G-U2b-14, G-U2b-15).
